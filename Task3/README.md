# Task 3 - Model Validation & Hyperparameter Tuning

## Objective
The objective of this task is to evaluate machine learning models using validation techniques, identify overfitting, perform hyperparameter tuning, and select the best-performing model.

## Dataset
- California Housing Dataset

## Models Used
- Linear Regression
- Ridge Regression
- Decision Tree Regressor

## Techniques Applied
- Data Preprocessing
- Feature Scaling
- Train-Test Split
- 5-Fold Cross Validation
- GridSearchCV for Hyperparameter Tuning
- Overfitting Analysis
- Model Performance Comparison

## Evaluation Metrics
- Root Mean Squared Error (RMSE)
- R² Score
- Cross-Validation RMSE

## Files Included
- AI_ML_Task3_Model_Validation_Tuning.ipynb
- Task3_Report_Overfitting_Tuning.pdf
- best_model_task3.pkl (Optional)
- scaler_task3.pkl (Optional)

## Results
The tuned Decision Tree model achieved the best performance with improved generalization after hyperparameter tuning. Cross-validation confirmed the model's reliability and reduced overfitting.
