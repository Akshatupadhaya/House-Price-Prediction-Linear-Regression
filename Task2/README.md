# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview
This repository contains AI/ML internship projects based on the California Housing Dataset. The objective is to analyze housing data, apply machine learning techniques, compare model performance, and improve prediction accuracy through feature engineering and optimization.

# 🤖 Task 2: Feature Engineering, Model Optimization & Performance Comparison

## 🎯 Objective
To build and compare multiple machine learning regression models for house price prediction and identify the best-performing model using evaluation metrics.

## 📊 Dataset
- California Housing Dataset
- Source: Scikit-Learn
- Target Variable: House Price

## ⚙️ Project Workflow
1. Data Loading and Inspection
2. Exploratory Data Analysis (EDA)
3. Correlation Analysis
4. Feature Scaling using StandardScaler
5. Train-Test Split (80:20)
6. Model Training
7. Model Evaluation
8. Model Comparison
9. Best Model Selection

## 🤖 Models Used
- Linear Regression
- Ridge Regression
- Decision Tree Regressor

## 📈 Evaluation Metrics
- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)
- R² Score

## 📉 Visualizations
- House Price Distribution
- Feature Distributions
- Correlation Heatmap
- Feature Correlation Analysis
- Scaling Effect Analysis
- Model Comparison Charts
- Actual vs Predicted Plots
- Residual Analysis
- Feature Importance Graphs
- Regression Coefficient Analysis

## 📁 Files Included
- AI_ML_Task2_Model_Comparison.ipynb
- Task2_Methodology_Results_Conclusion.pdf

## 🏆 Results
Multiple regression models were trained and evaluated. The best-performing model was selected based on R² Score, RMSE, and MAE. Performance comparison and visual analysis were used to validate model effectiveness.
